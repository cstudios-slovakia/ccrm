- **Time tracking: the Chrome extension is safe beside parallel timers** (`public/api/time_tracker_lib.php`, `time_tracker_ext.php`, `extensions/chrome-time-tracker/src/popup.ts`, `background.ts`, `scripts/probe-time-tracking/run.mjs` T17): extension Start and Stop take the per-user lock. Start always switches: it stops every running timer, settles them and answers with `stoppedAll`. Starting work that is already running is refused with 409 `already_running`, and the popup then shows that entry. Stop without an id while several timers run is refused with 409 `ambiguous` and the count. `running` now also returns `running[]`, `count`, `workedTodaySeconds` and `serverNow`. While several timers run, the popup shows "N timers running", today's worked clock and an "Open the app" button instead of Start and Stop, and the badge shows the count.
