- **Toggl import: repair entries imported earlier** (`api/time_entries.php`, `TogglImportPanel.tsx`): a new option "Repair entries imported earlier so they match Toggl" (off by default). An earlier import had put entries on other projects and stored their times 1–2 hours late, and a later import left them alone because the same Toggl entry is never imported twice. With the option on, an already imported entry gets the project its Toggl project is paired with now and Toggl's start, end and duration; rate and cost are recomputed as for a fresh import. An entry whose Toggl project is not paired keeps its project and only gets its times corrected; deleted entries stay deleted; locked entries are left to an administrator. Preview shows how many entries would change and how many move to another project.
- **Tests**: `togglImportMap.spec.ts` (the option is off by default, is sent when ticked, and the preview reports what would change).
