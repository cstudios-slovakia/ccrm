- **Orders can belong to a project** (`projects/ProjectOrdersTab.tsx`, `orders/OrderProjectLink.tsx`, `utils/projectOrders.ts`, `OrderDetailView.tsx`, `OrdersView.tsx`, `ProjectDetailsView.tsx`): new `orders.project_id` (indexed, synced by `sync.php`, `api/orders.php` and the MCP `create_order` / `update_order` / `list_orders`). The order editor has a searchable, clearable Project field (the customer's projects first), and the orders list shows the project as a link. The project card has an Orders tab (shown to roles that can see Orders while the Orders module is on) listing every linked order newest first with number, date, status, total and item count, and no order is marked as current. From the tab, "New order" opens an order prefilled with the project's customer and this project (and returns to the tab after saving), "Link existing order" offers the customer's unlinked orders, and each row can be unlinked.
