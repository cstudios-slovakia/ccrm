- **The cron job fits hosting that only visits a URL or runs a PHP file** (`api/cron.php`, `src/components/AutomationView.tsx`, new `CronSetupInstructions.tsx`): Automation → Settings now lists three ways to run the job every minute: the crontab command (token in a header), a URL with the token for a hosting cron that can only open a link (wget, e.g. Websupport), and `api/cron.php` as a PHP file. Run as a PHP file there is no HTTP request, so no token is needed and nobody outside the server can start it; the run takes the host name from the app's stored address, so e-mails and links look the same as from the URL call.
