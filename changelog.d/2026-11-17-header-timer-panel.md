- **The running timer in the header opens the full timer bar** (`timeTracking/HeaderTimerPill.tsx`, `TimerBar.tsx`, `Header.tsx`, `App.tsx`, `hooks/useRecentProjects.ts`): a click anywhere on the header pill except Stop drops the timer bar under it (title, project, billable, description, Stop) and a link to the module, so the running entry can be edited from any page. The pill had two red dots, a "recording" dot and the project's colour; it now has one, pulsing in the project's colour. Esc or a click outside closes the panel. On phones the timer title takes its own line instead of being squeezed by the project picker.
- **Running times no longer twitch as they tick** (`timeTracking/ClockDigits.tsx`, `EntryRow.tsx`, `TimeListView.tsx`, `TimeDayView.tsx`, `TimeTrackingMobileBar.tsx`, `TaskTimeControls.tsx`): the app font has no fixed-width digits, so `tabular-nums` did nothing and a "1" was narrower than a "0". Every digit now sits in a fixed slot, so the timer, the header pill, the list's running row and the day totals keep their width.
- **A grouped time entry row shows the whole group** (`utils/timeTracking.ts`, `timeTracking/EntryRow.tsx`, `TimeListView.tsx`): a row with a count badge showed only its first entry's duration, cost and time range (two entries of 0:37 and 0:45 read "0:37"). It now shows the sum and the span from the first start to the last end, and the badge expands the group to list and open each entry. Entries recorded by different people or with different descriptions are no longer grouped, since the row showed only the first one's "Recorded by" and description.
