- **Toggl import: "Import only my own Toggl entries"** (`TogglImportPanel.tsx`, `api/time_entries.php`, `api/time_tracking_lib.php`): a new checkbox imports the entries of the Toggl account the token belongs to and gives them to the signed-in user (or to whoever that Toggl user is mapped to), with no user mapping. Toggl is asked for that one user only, so a long period needs far fewer requests. It is on by default while no Toggl user is mapped; the override is per request and is not written into the saved mapping.
