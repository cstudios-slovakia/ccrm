- **Toggl import says why Toggl stopped answering** (`api/time_tracking_lib.php`, `api/time_entries.php`, `TogglImportPanel.tsx`, `src/utils/togglImport.ts`): "Toggl returned only part of the project list" gave no reason. `toggl_curl` now keeps the response headers and `ccrm_toggl_failure()` turns Toggl's answer into a cause the screen names: hourly request limit used up (402, with the wait Toggl gives), too many requests (429), token refused (401/403), or an outage with its HTTP status. A 429 is retried up to three times with the wait Toggl asks for. During an import a refusal now stops the run with that message instead of continuing through the remaining periods, and a refused workspace lookup is no longer reported as "Toggl is not configured".
- **A partial reload no longer shrinks the mapping list** (`TogglImportPanel.tsx`): rows Toggl did not return this time are kept from the previous load, and the warning says that saved pairings still apply to an import.
