- **One Project Manager plus assigned employees, everywhere** (`public/api/assigned_employees_migration.php`, `LeadEmployeesField`): leads and clients get an Employees field besides their Project Manager, like projects. Every Project Manager picker offers only users with the Project Manager role (a name saved earlier stays visible), and a project has exactly one Project Manager. Existing data is moved once: a project's extra managers become its employees, and a lead or client owned by someone without the Project Manager role gets that person as an employee instead. The "Convert lead to project" automation carries the lead's employees over.
