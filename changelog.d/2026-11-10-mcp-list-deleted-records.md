- **MCP `list_deleted_records`: which records were deleted since X** (`public/api/mcp_deleted.php`, `public/api/mcp.php`): a new read tool over the deletion tombstones. Each row has `entity`, `entity_id`, `label` (the name or title the record had), `deleted_at` (ISO 8601 with the CRM offset) and `deleted_by`. Filters: `entity`, `deleted_from` / `deleted_to` (the same input rules as `updated_from`), `sort_order` (oldest first by default, so a poller pages safely), `limit` (50, max 100) and `offset`. A row is returned only when the key's owner may view that record's module (leads and clients are split, tasks need the view-all-tasks permission, salaries and leave need their own permission); the filter runs in SQL, so pages stay full. Deletions are recorded from the version that added the table on; earlier ones are not known.
- **Tests**: `scripts/probe-mcp/run.mjs` (`changeSyncChecks`: ordering, ISO moments, the entity filter, inclusive/exclusive bounds, paging, malformed input, and visibility for leads-only, clients-only, projects-only, editor and nothing-role keys).
