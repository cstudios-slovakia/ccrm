- **Tasks: reopenings are recorded** (`public/sync.php`, `public/api/task_done.php`, `public/api/mcp_ext_writes.php`, `public/api/schema.php`): every time a finished task is set back to an open state, in the app or through the MCP `update_task` tool, the system now records who did it and when (`tasks.reopens_json`, migration, sync column healing and `entities_overview.md` updated). Reopenings made before this version cannot be recovered, so nothing is recorded for them.

Both widgets start empty ("—") and fill as tasks are reopened from now on.
