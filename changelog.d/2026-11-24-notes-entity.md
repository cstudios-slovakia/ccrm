- **Notes are their own entity** (`notes/EntityNotes.tsx`, `notes/NoteActivityRow.tsx`, `notes/ProjectNotesSection.tsx`, `utils/notesApi.ts`, `utils/noteActivity.ts`, `api/notes.php`, `api/notes_migration.php`, `LeadsDatagrid.tsx`, `ProjectDetailsView.tsx`): leads and projects have a Notes tab where notes are written, edited and deleted as yellow note blocks (author, date, "edited"), stored in a new `notes` table through `api/notes.php` and ready for other modules. Notes are no longer created from the timeline (the lead log form and the project's built-in event types lose "Internal note"); every add, edit and delete leaves a read-only "Note added / edited / deleted" line with a snippet on the timeline. A one-time migration moves existing hand-written lead notes and project "note" entries into the Notes tab and turns the original entries into those trace lines. The MCP `log_project_timeline_note` tool now creates a project note.
