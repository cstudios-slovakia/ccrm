- **Toggl import works for periods longer than a year** (`TogglImportPanel.tsx`, `src/utils/togglImport.ts`, `api/time_entries.php`, `api/time_tracking_lib.php`): the server refused any period over 366 days with `bad_request`, which the screen had no message for, so a multi-year import only showed "Could not save the time entry." The period now runs as consecutive windows of at most 92 days with progress on the button ("Importing 3 / 12…"), the counts are added up, and what finished windows imported stays visible if a later one fails. Range errors have their own codes and messages (`range_too_long`, `bad_range`, `toggl_unavailable`, plus a message for `bad_request`). A Toggl page that fails part-way is no longer treated as "no more entries": the result says some entries may be missing, and the token-owner fallback runs only when the reports API did not answer at all.
- **Toggl mapping: a project is listed once, archived ones say so** (`api/time_tracking_lib.php`, `TogglImportPanel.tsx`): a project id returned on two pages is kept once, and an archived Toggl project carries an "archived" tag, so two rows with the same name can be told apart.
- **Hold-to-confirm ring empties after confirming** (`src/components/ui/HoldToConfirm.tsx`): a button that stays on screen after the hold (the Toggl import) kept a full ring over it.
- **Tests**: `togglImport.test.ts` (`splitImportRange`: windows cover every day once, leap day, reversed range); `togglImportMap.spec.ts` (a 2024–2026 import goes out as short windows and the result adds up, the archived tag, the ring resets).
