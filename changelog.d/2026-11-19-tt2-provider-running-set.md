- **Time tracking: the provider holds the running set** (`src/hooks/useTimeTracking.tsx`, `src/utils/timeTrackingApi.ts`, `src/utils/timeTrackingRunning.ts`, `src/components/timeTracking/StartModePopover.tsx`, QA mock): `useTimeTracking` now keeps `running: TimeEntry[]`, `paused`, `presence` and the server clock offset, with `primaryRunning` and `isRunningTarget()` for single-timer UI. A Start while something runs follows the personal "Start while running" preference; with "Ask" a small popover offers "Switch to this" or "Run in parallel (N running)" and can remember the choice. Stop takes an entry id, `stopAll()` stops everything, Undo after a switch reopens every stopped timer, and the new refusals (parallel off, not permitted, limit, same project, ambiguous stop) have translated messages. With one timer the app looks as before.
