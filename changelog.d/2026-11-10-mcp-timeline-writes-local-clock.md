- **MCP timeline writes use the app clock** (`public/api/mcp.php`, `mcp_ext_writes.php`): stage changes, lead conversion, new contacts, task comments, `log_communication` and `create_client` stamped `timeline_events.timestamp` with MySQL `NOW()`, which is UTC on a server whose MySQL runs in UTC, while the app writes local time into the same column. New entries now carry the app's local wall time, so a call logged through MCP sorts correctly beside the app's own entries. Older MCP-written entries keep their old stamp.
