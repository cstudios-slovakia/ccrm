- **Toggl import: pick which Toggl user is you** (`TogglImportPanel.tsx`, `api/time_entries.php`, `api/time_tracking_lib.php`): "import only my entries" no longer means the owner of the API token (the token is often an administrator's). The option is now "Import only one Toggl user's entries, to me" with a picker of the workspace's Toggl users; the one with the signed-in person's e-mail is preselected. Those entries go to the signed-in user (or to whoever that Toggl user is mapped to), nobody else's are read, and no user mapping is needed. It is on by default only when nobody is mapped and a matching Toggl user was found.
- **Tests**: `togglImportMap.spec.ts` (the suggested user is preselected, another can be picked, and `onlyUser` goes out with the request).
