- **Toggl import mapping lists every Toggl project, not just the first 1000** (`public/api/time_tracking_lib.php`, `public/api/time_entries.php`, `src/components/timeTracking/TogglImportPanel.tsx`): the catalog stopped after 5 pages of 200, so in a large workspace newer projects (for example one created last month) never appeared and could not be paired. It now reads every page, includes archived projects (they keep their tracked time), retries once on Toggl's rate limit, and shows a warning when the list is still incomplete. Mapped projects and users are listed first (the order is fixed per load, so a row does not jump while you pick).
