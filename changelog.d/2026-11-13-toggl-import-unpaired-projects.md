- **Toggl import no longer drops entries into "no project"** (`public/api/time_entries.php`, `src/components/timeTracking/TogglImportPanel.tsx`): a new option, on by default, skips entries from Toggl projects that are not paired yet. They stay in Toggl and come in with their project once you pair it. Entries imported earlier without a project now get one: once their Toggl project is paired, the next import fills it in (and the billable rate that goes with it). An entry whose project was set by hand, or that was deleted, is left alone, and for a non-administrator a locked entry is only counted. The preview now says how many entries stay in Toggl, how many land without a project, and how many earlier entries will get their project.
