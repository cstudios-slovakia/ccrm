- **Time tracking: allocation engine for parallel timers** (`src/utils/timeAllocation.ts`, `public/api/time_allocation.php`): pure functions that split one person's real clock time between overlapping timed entries (worked time), identical in TypeScript and PHP. Not wired to any caller yet.
- **Tests**: shared fixtures `scripts/fixtures/time-allocation-cases.json` (the brief, staggered, remainder and billing examples, a running entry, ties, touching and contained intervals, a hand-computed five-entry case) run by `timeAllocation.test.ts` and `npm run test:time-allocation`; both also check invariants I1-I4 on 200 seeded random cases.
