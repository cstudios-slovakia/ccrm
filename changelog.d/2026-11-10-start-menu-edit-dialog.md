- **Start menu edit mode is a dialog of its own** (`StartMenu.tsx`, `menuEdit/StartMenuEdit*.tsx`): "Upraviť menu" now has a header with search, "Nová skupina" and a more-options menu (custom dashboard, restore defaults with an in-app confirmation), a start-screen dropdown with a legend, a four-column grid with a row per module (pin toggle, ⋯ menu with move to group, move up/down with Alt ↑/↓, hide) and a group menu (rename inline, move left/right, delete with confirmation and Undo). The old banner, inline pickers and hold-to-confirm delete are gone; below `lg` the mobile editor takes over.
