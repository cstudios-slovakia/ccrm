- **Changelog fragments replace per-commit version bumps** (`scripts/release/collect-changelog.mjs`, `changelog.d/`, `.agents/rules/commit-and-versioning.md`, `.agents/rules/make-a-build.md`): a feature or fix commit now adds one `changelog.d/<date>-<slug>.md` file and leaves `version.ts` and the changelog alone; "make a build" collects all fragments into one new `### v...` section, bumps the patch number once and deletes the fragments. The unused root `increment-version.js` is removed, the collector replaces it.
- **Tests**: `scripts/release/collect-changelog.test.mjs` (version bump keeps the codename, CRLF and LF changelogs keep their line endings, fragments sorted and validated, dry run writes nothing, empty run refused).
