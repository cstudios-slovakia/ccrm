- **The floating copilot orb no longer slows every screen** (`src/components/executive/FloatingCopilotOrb.tsx`): the orb's avatar now moves only while the pointer is over it. Moving all the time, it made the browser draw a new frame continuously; on a long list (the leads pipeline with about 500 rows) each frame took 200-300 ms, so hovering rows and expanding panels stuttered. Measured on such a list: about 15 frames per second with the orb moving, 60 with it still.
