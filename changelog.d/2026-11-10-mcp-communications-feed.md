- **MCP `list_communications` is a cross-record activity feed** (`public/api/mcp_lists_crm.php`): `lead_id` is now optional; without it the tool lists calls, mails, notes and stage changes across every lead and client the key may read (the leads/clients split is applied per row, plus the mailbox gate), each row with `lead_name`. New `from`/`to` (app local time), `sort_order`, `offset` and an id tiebreak; `timestamp_iso` carries the offset next to the local `timestamp`. `get_lead`, `get_client_dossier`, `list_documents` and `list_files` return `timestamp_iso` too.
