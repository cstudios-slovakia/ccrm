- **Leads list: Employees column and filter** (`LeadEmployeeChips`, `useLeadFacets`): a new "Employees" column after Project Manager shows a lead's assigned employees (two chips plus "+n"), and a new Employees filter sits next to the manager filter. The manager filter offers Project Managers (plus anyone already owning a lead), the employees filter everyone else. Search also matches employees.
- **Automatic lead assignment hands leads to Project Managers only** (`api/auth.php`, Settings → Pipeline): the rotation and its settings card list only users with the Project Manager role; on an install where nobody has the role, every user as before.
