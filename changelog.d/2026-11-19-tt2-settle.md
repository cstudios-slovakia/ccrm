- **Time tracking: overlapping entries no longer cost twice** (`public/api/time_settle.php`, `time_entries.php`, `time_tracker_lib.php`, `mcp_ext_modules.php`, `ticket_time_migration.php`, `demo_seed/time.php`, `time_cost.php`, `src/utils/timeCost.ts`): an entry's cost now comes from its worked time (its share of the person's real clock time) and keeps four decimals. Two entries of one person that overlap split the cost of the shared stretch, while each still bills its full project time. Creating, editing, stopping, deleting, restoring, importing or re-pricing an entry re-settles its neighbours too. Non-admins can no longer create or move an entry so it overlaps a locked entry. A guard test (`scripts/agent/time-cost-writers.test.mjs`) fails if any code other than `ccrm_tt_settle()` writes `cost` or `worked_ms`.
