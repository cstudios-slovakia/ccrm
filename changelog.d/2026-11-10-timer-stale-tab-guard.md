- **Time tracking: Start on a timer that is already running no longer splits it into a new entry** (`public/api/time_entries.php`, `src/hooks/useTimeTracking.tsx`): a second tab, another device or an agent could still show "Start" for a running timer, and pressing it stopped the timer and began a fresh entry. The server now refuses a start of the same target (project, task, ticket and text) and the screen adopts the running timer with a toast. Tabs in the same browser tell each other about every start and stop, and a window refreshes the running timer when it gets focus.
- **Projects: Time tab entries show when they were tracked** (`src/components/timeTracking/ProjectTimeTab.tsx`): each row shows its date and start–end time, an entry without a title falls back to its note or "No description", and an entry shorter than a minute shows its seconds instead of `0:00`.
- **Tests**: `timeTracking.spec.ts` covers a stale screen pressing Start on the running project timer; the time-tracking probe checks the server refuses it; the e2e mock follows the same rule.
