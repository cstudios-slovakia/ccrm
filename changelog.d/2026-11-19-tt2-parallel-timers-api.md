- **Time tracking: parallel timers on the server** (`public/api/time_entries.php`, `time_lock.php`, `time_parallel.php`, `time_parallel_migration.php`, `time_settle.php`, `schema.php`, `entities_overview.md`): several timers of one person may run at once when the company turns parallel tracking on and the role has `time_tracking_parallel`. `start` takes `mode` (`switch`, the default, stops every running timer; `parallel` stops nothing and is refused with `parallel_disabled`, `parallel_forbidden`, `parallel_limit`, `same_project` or `already_running`), `stop` takes `id` or `all` (several running without an id = `ambiguous`), `undo_start` reopens every stopped timer (`stoppedIds`), and `GET ?running=1` returns `running[]`, `paused[]`, `presence` and `serverNow` next to the old `entry`. The unique "one running timer" key becomes a plain index; every timer change takes a per-user lock row in the new `time_presence` table instead. Worked time is shared between all running timers. Old clients (no `mode`, reading `entry`) behave as before.
