- **AI Assistant (MCP): setup prompt** (`src/components/mcp/McpWebConnectPanel.tsx`, `src/utils/mcpSetupPrompt.ts`, `src/components/mcp/mcpUi.tsx`, `McpAssistantSettings.tsx`): the "Web app / connector" tab now has two sub-tabs. The default, "Setup prompt", is one message with the server URL, header and key already filled in, to paste into any AI app: apps that can run commands or edit files (Claude Code, Codex, Gemini CLI, Cursor, VS Code, Windsurf) add the connection themselves at user level and test it; chat apps (claude.ai, ChatGPT) say they cannot change their own settings and guide the user through the clicks. The prompt tells the agent not to repeat the key, not to put it in project files or a URL, and to remind the user to delete the conversation. A warning says the prompt contains the key; without the full key the prompt cannot be copied and a button generates one (asking first when a key exists). "Manual setup" keeps the previous fields.
