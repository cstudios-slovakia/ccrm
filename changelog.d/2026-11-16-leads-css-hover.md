- **Hovering a lead no longer re-renders the leads list** (`src/components/LeadsDatagrid.tsx`, `src/utils/leadRowHover.ts`, `index.css`): the row highlight and the stage strip opening are now plain CSS driven by an attribute on the hovered rows, not React state on the list. On a 500-row list each hover in and out cost 350-560 ms of script and the strip drew 3-5 frames; done with styles it draws 30-45. The strip now opens upward over the bottom padding of its own row instead of pushing the rows below it down.
