- **Stock tables carry a change moment** (`public/api/schema.php`, `public/sync.php`, `entities_overview.md`): `suppliers`, `warehouse_items`, `warehouse_batches` and `warehouse_movements` get `updated_at TIMESTAMP(3)` (created in `CREATE TABLE`, added by the idempotent migration `ccrm_migrate_stock_updated_at`, healed in `sync.php` before the transaction). It lets the MCP lists answer "what changed since X?" for stock. The migration stamps every existing row with the time it runs, so the first poll after the deploy reports every existing row of these four tables as changed.
