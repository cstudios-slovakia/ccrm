- **MCP `list_documents` and `list_files` respect the leads/clients split** (`public/api/mcp_lists_crm.php`, `mcp_ext_ops.php`, `mcp.php`): without `lead_id`, `list_documents` and `list_files source=lead` returned rows of records the key could not read (a leads-only key saw client documents and the reverse). The split now runs in SQL, joined on `leads`; both tools also take `offset`, order with an id tiebreak and return `timestamp_iso`. `list_files` hides e-mail events from keys without the mailbox module, and the task scope of every MCP tool now matches the caller by name or e-mail, like the app.
