# Update 1.8 (Codename: Imbe)

This document tracks all new features, architectural changes, schema migrations, and improvements introduced in the 1.8 Imbe update cycle.

---

### v1.8.2-Imbe (2026-08-18)
* **Dedicated Full-Page Product Detail & Editor Screen (Replaced Popup Modal)**:
  * **Dedicated 360° Product View (`src/components/WarehouseView.tsx`)**:
    * Replaced the popup modal dialog (`isItemModalOpen`) for Product Creation and Editing with a dedicated full-screen workspace.
    * **Header & Breadcrumbs**: Added navigation breadcrumb (`Sklad / Katalóg tovaru / [Product Name]`), stock status badge (In Stock / Low Stock / Out of Stock), SKU badge, category pill, back button (`← Späť na skladové zásoby`), delete button with confirmation, and primary Save action button.
    * **Left Column (2/3 Workspace)**:
      * *Základné informácie*: Product name, SKU code, Barcode/EAN with icon, Unit of measure picker (`ks`, `m²`, `bm`, `m³`, `kg`, `l`, `balenie`, `paleta`), Category with quick-suggestion pills (*Veľkoformátové dosky*, *Prírodný kameň*, *Stavebná chémia*...), and detailed multiline description.
      * *Cenotvorba, WAP a Kalkulátor ziskovosti*: Average Purchase Price (WAP), Last purchase price, Selling price (excl. VAT), and real-time live profitability widget computing gross profit per unit, gross margin %, and markup over cost with color-coded profit classification badge.
      * *Skladové limity a pozícia*: Default bin/rack position (`MapPin`), minimum alert stock threshold, optimal target stock, and FEFO expiry tracking toggle.
      * *Rozdelenie zásob po skladoch*: Multi-warehouse breakdown table displaying physical on-hand quantity, reserved quantity for orders, available stock, and specific bin position across *Hlavný sklad Bratislava*, *Výrobný sklad Trnava*, etc.
    * **Right Column (1/3 Workspace)**:
      * *Fotografia a vizuál tovaru*: Large high-resolution image preview box with fallback icon and instant URL input.
      * *Rýchle skladové operácie*: One-click shortcuts to create Receipt (*Príjemka - PRI*) or Issue (*Výdajka - VYD*) with this item pre-selected.
      * *Aktívne šarže a exspirácie (FEFO)*: List of active lot batches with expiration dates, quantities, and status semaphores (🟢 OK, 🟡 < 30 days, 🔴 Expired).
      * *História pohybov tovaru*: Timeline of recent inward/outward/transfer warehouse documents affecting this product with document numbers and quantities.
    * **Interactivity**: Clicking any product row or edit button in the main catalog table directly opens the dedicated product view.

### v1.8.1-Imbe (2026-08-18)
* **Warehouse & Inventory Management Module (Complete End-to-End Implementation)**:
  * **Database Architecture & DDL (`api/schema.php`, `public/api/schema.php`, `entities_overview.md`)**:
    * Created 7 relational warehouse tables: `warehouses`, `suppliers`, `warehouse_items`, `warehouse_stock`, `warehouse_batches`, `warehouse_movements`, `warehouse_movement_items`.
    * Implemented strict foreign keys with cascading deletions, indexes on search keys (SKU, barcode, document number, expiration date), and JSON column support for supplier contacts.
    * Documented Section 8 in [entities_overview.md](file:///Users/erik/Documents/vibe%20coding/crm/entities_overview.md) following standard repository guidelines.
  * **Sync Engine & Protocol Extension (`sync.php`, `public/sync.php`)**:
    * Added warehouse tables to data version hashing (`ccrm_compute_data_version`).
    * Implemented GET serialization querying all 7 tables and mapping snake_case DB columns to camelCase TypeScript schemas.
    * Implemented transactional POST handlers for full upserts and delta deletes across warehouses, suppliers, item catalog, stock balances, FEFO batches, and stock movements with nested items.
  * **Seeded Demo Data (`scripts/seed_demo_warehouse.php`)**:
    * Seeded 2 warehouses: *Hlavný sklad Bratislava (WH-BA-01)* and *Výrobný sklad Trnava (WH-TT-01)*.

    * Seeded initial stock levels, FEFO batches with status semaphores, and historical movement documents (`PRI-2026-0001`, `PRI-2026-0002`, `VYD-2026-0001`).
  * **Frontend Architecture & Navigation (`src/types/index.ts`, `src/utils/translations.ts`, `src/components/Sidebar.tsx`)**:
    * Added comprehensive TypeScript interfaces for all warehouse entities.
    * Added full trilingual translations (Slovak, English, Hungarian) in [src/utils/translations.ts](file:///Users/erik/Documents/vibe%20coding/crm/src/utils/translations.ts).
    * Added `#1e3a8a` Navy Blue luxury warehouse item with `Package` icon in [src/components/Sidebar.tsx](file:///Users/erik/Documents/vibe%20coding/crm/src/components/Sidebar.tsx).
  * **Luxury Warehouse Component (`src/components/WarehouseView.tsx`)**:
    * Built master Navy Blue interface with 5 functional tabs:
      1. **Prehľad zásob (Stock Inventory)**: Live stock levels, category filters, low stock warnings, WAP costing, and stock valuation.

    * Integrated interactive modals: Product catalog creation/editing, Receipt (PRI), Issue (VYD) with Lead timeline auto-logging, Transfer (PRE), Supplier management, and Printable Delivery Note (*Dodací list*).
  * **Application Wiring & Integration (`src/App.tsx`)**:
    * Integrated safe lazy loading, local state hooks, delta sync engine bindings, and routing.
    * Integrated Lead detail timeline linking delivery notes directly to the client's activity feed.
