# CCRM Version 1.9-Jackfruit Changelog

## [1.9.0-Jackfruit] — 2026-08-25

### ✨ New Features & Enhancements

#### 1. Invoices & Price Offers Engine (`InvoicingView`)
- **Three Document Generation Modes**:
  - **Default Built-in Template**: Pixel-perfect custom PDF price offer template structured with all 10 core business blocks (Header, Client Metadata, Trust-building Greeting, 4 USP highlight cards, Scope of delivery & items table, Price highlight banner, 3 Key parameters, Call-to-action next steps, Sign-off, and Billing footer with social proof references).
  - **Custom AI PDF Template**: Upload any sample PDF quote; AI extracts layout, branding, and styling while automatically guaranteeing all essential fields from the default schema are included.
  - **External API Integrations (SuperFaktura & iDoklad)**: Direct integration with SuperFaktura and iDoklad for issuing official invoices/quotes and fetching server-rendered PDFs.
- **Lead, Client & Warehouse Product Pairing**:
  - Automatically auto-fills client corporate identifiers (IČO, DIČ, IČ DPH), contacts, and billing address upon selecting a Lead/Client.
  - Interactive Warehouse Product picker with SKU, stock quantity checks, default pricing, and custom line items.
- **Lead Timeline & Financial Record Synchronization**:
  - Generates and attaches PDF documents directly to the Lead's timeline as an `offer` or `invoice` event.
  - Optionally logs confirmed documents into `FinancialManagement` income records.

#### 2. Invoicing & Billing Settings Section
- **Company Identity & Branding**: Logo uploader with live preview, full business address, and corporate registration IDs (IČO, DIČ, IČ DPH).
- **Banking Coordinates**: IBAN, SWIFT / BIC, and Bank Name.
- **Default Document Terms**: Configurable default payment due days, default VAT rate (%), default warranty period, default project duration, and editable 4 USP value proposition cards.
- **External API Credentials**:
  - SuperFaktura configuration (Email, API Key, Company ID, Sandbox toggle, and live Connection Tester).
  - iDoklad configuration (Client ID, Client Secret, Sandbox toggle, and live Connection Tester).
- **Custom AI Template Manager**: Upload sample PDFs, trigger AI structure parsing, and manage custom template blueprints.

#### 3. Backend & Sync Architecture
- **New API Endpoints**:
  - `api/generate_pdf_template.php`: AI-powered PDF schema extraction and template synthesis.
  - `api/superfaktura.php`: SuperFaktura API connector (estimates, invoices, connection test, and PDF retrieval).
  - `api/idoklad.php`: iDoklad OAuth2 connector (price offers, issued invoices, connection test, and PDF retrieval).
- **Database Schema Migrations**:
  - Added `invoices_offers` and `invoice_offer_items` tables with full relational indexing and delta sync in `sync.php`.
