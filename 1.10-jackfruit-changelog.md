# Update 1.10 (Codename: Jackfruit)

This document tracks all new features, architectural changes, schema migrations, and improvements introduced in the 1.10 Jackfruit update cycle.

---

### v1.10.4-Jackfruit (2026-09-11)

- **Interactive Knowledge Graph Entity Explanation Popover (`src/components/sai/SwarmGraphCanvas.tsx`)**:
  - **Direct Above-Entity Popover**: Clicking any stakeholder entity in the Knowledge Graph Canvas now displays a dedicated popover card positioned directly above the clicked node, complete with a directional caret pointer.
  - **Rich Contextual Explanation**: Shows entity name, category badge, entity type color accent, full summary explanation of the entity's role/bias, and active graph relations (e.g. `REGULATES → Target`).
  - **Dynamic Viewport Flipping & Clamping**: Automatically flips below the node if positioned near the top boundary of the canvas (`y < 125px`), with horizontal clamping to prevent clipping at canvas edges.
  - **Connected Graph Focus**: Dynamically highlights edges and neighboring entities connected to the selected entity while dimming unrelated nodes, improving topological readability.
  - **Intuitive Dismissal**: Clicking the close button, clicking the entity again, or clicking empty space on the graph canvas instantly closes the popover.

### v1.10.3-Jackfruit (2026-09-11)

- **Sticky Interrogation Chatbot Card on SAI Results (`src/components/sai/StrategicReportView.tsx`, `SaiModule.tsx`, `QaAssistantDrawer.tsx`)**:

  - **Adaptive Height Calculation**: Set responsive height constraint (`h-[calc(100vh-210px)] min-h-[500px] max-h-[820px]`) ensuring the interrogation input and send button stay fully visible within the viewport across laptop and desktop displays.
  - **Internal Independent Scroll**: Preserved smooth internal scrolling for the chat message history while scrolling through the main strategic report independently.

### v1.10.2-Jackfruit (2026-09-11)

- **Configurable CRM Grounding Sources & Selective Ingestion (`src/components/sai/CreateRehearsalView.tsx`, `SaiModule.tsx`, `CrmContextExtractor.php`, `SwarmManager.php`, `checkpointClient.ts`, `crmContextService.ts`)**:
  - **Granular Source Selection Controls**: Added an interactive CRM Grounding Sources control panel on the Rehearsal Creation view, enabling users to selectively toggle individual CRM repositories on or off before launching a rehearsal.
  - **6 Modular Grounding Sources Supported**:
    1. `active_leads`: Active Pipeline Leads (in-progress deals, discovery accounts, unclosed opportunities).
    2. `existing_clients`: Existing & Won Retainers (active accounts, retainer clients, won contracts).
    3. `lost_deal_objections`: Lost Deals & Objections (historical sales resistance, price sensitivity, rejection reasons).
    4. `competitor_intel`: Competitor Mentions & Intel (rival platform references, competitor pricing discussions).
    5. `meeting_notes`: Meeting Transcripts & Discovery Notes (verbal feedback, discovery call transcripts).
    6. `client_emails`: Client Inbound Emails (inbound inquiries, scope discussions, email correspondence).
  - **Bulk Actions & Visual Badges**: Provided "Select All" and "Clear All" convenience toggles, dynamic status counters (`X of 6 Active`), active ring highlights, and source count badges on rehearsal history cards.
  - **Zero-Source Safeguard**: Added fallback handling and visual warning banner when all sources are disabled, allowing pure scenario grounding based solely on the user's seed memo.
  - **Draft State Persistence**: Selected CRM data sources are stored in the server checkpoint state and cleanly restored when reopening or editing saved rehearsal drafts.

### v1.10.0-Jackfruit (2026-09-11)

- **Swarm Artificial Intelligence (SAI) Engine (`api/swarm.php`, `src-php/Swarm/`, `src/utils/swarm/`, `src/components/sai/`)**:
  - **Hybrid Client-Orchestrated Architecture**:
    - Built a fully autonomous, multi-agent predictive simulation engine running in browser runtime (React 19 / TypeScript) while persisting snapshots to PHP 8 / MySQL.
    - Eliminates Python, Docker, Celery, and Redis dependencies from customer environments.
    - Integrated Screen Wake Lock API and `beforeunload` protection to prevent machine sleep or accidental tab closing during multi-round rehearsals.
  - **Dynamic Database Sharding & Checkpointing (`src-php/Swarm/SwarmManager.php`, `src/utils/swarm/checkpointClient.ts`)**:
    - Dynamic per-simulation table sharding (`sim<sim_id>_nodes`, `sim<sim_id>_edges`, `sim<sim_id>_agents`, `sim<sim_id>_posts`) prevents index bloat and ensures high-throughput writes.
    - Round-by-round asynchronous JSON snapshot checkpointing allows instant recovery and zero data loss on browser crash.
    - Atomic table dropping on deletion guarantees zero orphaned records.
  - **Temporal CRM Grounding (`src-php/Swarm/CrmContextExtractor.php`, `src/utils/swarm/crmContextService.ts`)**:
    - Injects real CRM leads, client interactions, and historical lost deal objections into the simulation seed.
    - Configurable lookback horizon (6, 12, or 24 months) prevents 10-year stale data contamination.
  - **Native Multi-Factor Linear RecSys Algorithm (`src/utils/swarm/recsysEngine.ts`)**:
    - Native TypeScript / PHP linear recommendation formula ($0.4 \cdot \text{Recency} + 0.3 \cdot \text{Popularity} + 0.3 \cdot \text{Relevance}$) dynamically populates candidate feeds for each agent turn.
  - **Secure Server-Side LLM Proxy (`api/swarm.php`)**:
    - Proxies all LLM completions via authenticated server endpoints, decrypting CCRM's existing system OpenAI keys (`INTEGRATIONS_CONFIG`) without exposing raw credentials to the client.
  - **Mandatory Pre-Flight Token & Cost Estimator (`src/components/sai/PreflightEstimatorModal.tsx`)**:
    - Pre-flight modal calculates projected token volume and API cost before simulation start, requiring user acknowledgment to prevent unexpected charges.
  - **Live War Room & Visualizations (`src/components/sai/LiveWarRoom.tsx`, `SwarmGraphCanvas.tsx`, `SocialFeedStream.tsx`)**:
    - Real-time animated SVG knowledge graph showing active stakeholder nodes and posting ripples.
    - Cascading dual-platform (Twitter/X & Reddit) social feed stream with real-time sentiment tracking and circadian diurnal pacing clock.
  - **Executive Strategic Briefing & Playbook (`src/components/sai/StrategicReportView.tsx`, `src/utils/swarm/reportSynthesizer.ts`)**:
    - ReAct Chief Intelligence Analyst generates comprehensive post-simulation analysis.
    - Includes mandatory chapter: *"What Strategy to Use to Achieve the Goal?"* with actionable countermeasures, competitor retaliation analysis, and sales objection rebuttals.
  - **Interactive Interrogation Drawer (`src/components/sai/QaAssistantDrawer.tsx`, `src/utils/swarm/chatAssistant.ts`)**:
    - Slide-out drawer for multi-turn Q&A with the Chief Analyst or direct 1-on-1 cross-examination of any simulated agent persona.
  - **Interactive Demonstration Mode & Zero-Quota UX Evaluation (`src/utils/swarm/demoData.ts`, `src/components/sai/SaiModule.tsx`)**:
    - Added a dedicated Demo Mode toggle in the top navigation bar and full synchronization with system-wide `isDemoMode`.
    - Integrated pre-computed Enterprise Pricing Rehearsal demo dataset (+25% increase, 99.9% uptime SLA, WhatsApp developer bridge) for instantaneous exploration with zero API tokens consumed.
    - Simulated fast local round progression with realistic agent turn pacing, live graph ripples, circadian clock tracking, and ReAct strategic briefing compilation.
    - Added contextual simulated interrogation in the Q&A Drawer for both the Chief Intelligence Analyst and 1-on-1 interviews with specific agent personas (Sarah Jenkins, Marcus Vance, David Chen, Dr. Elena Rostova).
  - **Navigation & Brand Identity (`src/components/icons/FlockIcon.tsx`, `src/components/Sidebar.tsx`, `src/components/StartMenu.tsx`, `src/App.tsx`)**:
    - Added top-level navigation item labeled **"SAI"**.
    - Designed custom vector `FlockIcon` depicting a flying flock of birds in dynamic V-formation with a rich purple-to-emerald gradient (`from-purple-600 via-indigo-500 to-emerald-400`).
