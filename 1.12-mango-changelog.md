# Update 1.12 (Codename: Mango) — New Features

This document tracks all new features, architectural changes, schema migrations, and improvements introduced in the 1.12 Mango update cycle.

### v1.12.10-Mango (2026-10-12)
- **Canonical CCRM View Layout for Orders (`src/components/OrdersView.tsx`, `src/App.tsx`)**:
  - Aligned the Orders list view with the standardized CCRM layout system used across Invoicing, Warehouse, and Projects.
  - **PageHeader**: Replaced ad-hoc top headers with the canonical `PageHeader` component featuring icon, localized title, subtitle, optional read-only badge, and unified action buttons ("Order settings" link & "+ New order").
  - **StatGrid & StatTiles**: Standardized the KPI summary strip using `StatGrid count={4}` and `StatTile` with curated tones, metric values, and comparative deltas:
    - *Total Orders* (indigo tone, count & new orders delta)
    - *Awaiting Prep* (sky tone, combined count of new & processing orders)
    - *Total Volume* (emerald tone, gross turnover with currency)
    - *Unpaid Amount* (amber tone, unsettled balance & unpaid order count)
  - **Tabs Lifecycle Navigation**: Integrated standard `Tabs` component with count badges for each order stage (*All*, *New*, *Processing*, *Shipped*, *Delivered*, *Cancelled*).
  - **Standard Search & Filters Bar**: Implemented white rounded-3xl container matching `InvoicingView` with debounced search input (with clear button) and two `CustomSelect` dropdowns for customer type (*All*, *Registered clients*, *Guests only*) and payment status (*All*, *Paid only*, *Unpaid only*).
  - **Canonical Data Table**: Refactored the orders grid into a responsive, clean table in a rounded-3xl white card container (`table min-w-220 text-ui hover:bg-slate-50/80`):
    - *Order no.* (interactive font-mono button opening order detail, with localized issue date)
    - *Customer* (name with Client / Guest badge, CRM link or "+ To client" conversion button, delivery city)
    - *Delivery & Tracking* (carrier pill with truck icon, copyable mono tracking code badge with check animation)
    - *Items* (total quantity count + product vs. service breakdown)
    - *Payment* (paid vs unpaid status pill + payment method)
    - *Total gross* (bold font-mono amount with currency + net amount excl. VAT)
    - *Status* (`CustomSelect` with dynamic status color borders for instant inline status changes)
    - *Actions* (warehouse dispatch, invoice generation, edit order, and delete order)
  - **EmptyState Integration**: Clean `EmptyState` component with localized title, description, and primary action when no orders match active filters.
  - **Strict View Size Compliance**: Zero arbitrary font sizes or pixel spacing, 100% compliant with `viewSizeGuard.test.ts`.

### v1.12.9-Mango (2026-10-12)
- **Clickable Order Numbers for Instant Opening (`src/components/OrdersView.tsx`, `src/components/ClientsView.tsx`, `src/App.tsx`)**:
  - Made the order number and shopping cart icon in the main Orders datagrid interactive buttons that immediately open the order editor / detail view (`handleOpenEdit`).
  - Made the order number in the Client Detail → Orders tab (`ClientsView.tsx`) a clickable link that deep-links directly into that order.
  - Added `initialSelectedOrderId` support and route hash resolution (`orders/:orderId`) in `App.tsx` and `OrdersView.tsx` to automatically open the target order when navigating or linking from other views.

- **Configurable Payment Methods in Settings (`src/components/PaymentMethodSettings.tsx`, `src/components/SettingsView.tsx`, `src/utils/payment.ts`, `src/types/index.ts`)**:
  - Added configurable payment methods (`paymentMethods?: string[]`) and default payment method selection (`defaultPaymentMethod?: string`) to `CompanyBillingSettings`.
  - Default payment options include: **Prevod na účet (Bank wire transfer)**, **Dobierka (Cash on Delivery)**, **Platobná karta (Card)**, and **Hotovosť (Cash)**.
  - Implemented an interactive management panel in **Settings → Orders** (`/settings/orders`):
    - Visual list of configured payment methods displaying display index `#1, #2...`, payment method icons (credit card, bank landmark, cash banknote, delivery truck), and default method badge.
    - 1-click "Set default" button to designate which method is pre-selected for new orders.
    - Up / Down arrow reordering and drag-and-drop support.
    - Inline custom payment method creation with enter-key shortcut and duplicate prevention.
    - Quick-add suggestions for common payment methods (Prevod na účet, Dobierka, Platobná karta, Hotovosť, PayPal, Apple Pay / Google Pay, Faktúra so splatnosťou).
    - 1-click "Reset to defaults" action.
    - Automatic state synchronization with `companyBillingSettings`.
- **Dynamic Payment Method Selection in Orders (`src/components/OrderDetailView.tsx`, `src/components/OrdersView.tsx`)**:
  - Replaced hardcoded payment method options in order editor with dynamic methods from `companyBillingSettings.paymentMethods`.
  - Automatically pre-selects the configured `defaultPaymentMethod` when creating new orders.
  - Added defensive inclusion of historical/custom payment methods on existing orders to prevent data loss.

- **Configurable Shipping Methods in Settings (`src/components/ShippingMethodSettings.tsx`, `src/components/SettingsView.tsx`, `src/utils/shipping.ts`, `src/types/index.ts`)**:
  - Added configurable shipping carrier and delivery methods (`shippingMethods?: string[]`) to `CompanyBillingSettings`, defaulting to standard regional carriers: **DPD Kuriér, Packeta / Zásielkovňa, GLS Expres, Slovenská pošta, and Osobný odber**.
  - Implemented an interactive, modern management card in **Settings → Orders** (`/settings/orders`):
    - Visual list of configured shipping methods displaying display index `#1, #2...` and carrier type badges (courier truck, parcel locker/box, post office, physical pickup).
    - Reordering controls with Up / Down arrows and drag-and-drop support so users can customize the exact button order in order details.
    - Inline "Add Custom Shipping Method" input with enter-key shortcut and duplicate prevention.
    - Quick-add suggestions for common carriers (DPD Kuriér, Packeta, GLS Expres, SPS Kuriér, Slovenská pošta, Osobný odber, DHL Express, Kuriér na adresu).
    - 1-click "Reset to defaults" action to easily restore the original 5 carrier options.
    - Automatic state synchronization with `companyBillingSettings` without requiring a full page refresh.
- **Dynamic Shipping Carrier Selection in Orders (`src/components/OrderDetailView.tsx`)**:
  - Replaced hardcoded carrier buttons with dynamic buttons populated from `getAvailableShippingMethods(companyBillingSettings)`.
  - Added defensive inclusion of `formData.shippingMethod` to ensure existing or custom historical orders never lose their carrier badge.
  - Added 1-click toggle-off support if an already active method button is clicked again.

- **Unassigned Client Default for New Orders (`src/components/OrdersView.tsx`, `src/components/OrderDetailView.tsx`)**:
  - Removed default pre-selection of the first CRM lead (`leads[0]`) when creating a new order (`clientId: null`).
  - Added an intuitive empty state in the Customer Profile panel with an informative notice ("No client selected" / "Nie je vybraný žiadny klient") explaining that users can search and attach a registered client or switch to Guest Checkout.
  - Added quick 1-click "Change / Detach" actions on both the search input clear control and the synced client card header, allowing users to effortlessly unbind or swap the linked client.

### v1.12.5-Mango (2026-10-12)
- **Configurable VAT Rates in System Settings (`src/utils/vat.ts`, `src/types/index.ts`, `src/components/SettingsView.tsx`)**:
  - Added configurable VAT rates (`vatRates?: number[]`) to `CompanyBillingSettings`, defaulting to standard Slovak / EU tax reform rates: **23%, 19%, 10%, 5%, and 0%**.
  - Default VAT rate prefilled for new order and invoice items is set to **23%** (`DEFAULT_STANDARD_VAT_RATE = 23`).
  - Implemented an interactive VAT management card in Settings → Invoicing:
    - Active VAT rate pills with default indicator badge, 1-click "Set default", and removal buttons.
    - Inline "Add Custom VAT Rate" input with percentage formatting and enter-key submission.
    - Quick "Reset to defaults (23, 19, 10, 5, 0)" button to easily restore standard rates.
    - Default VAT rate selector allowing users to designate the standard rate pre-selected when creating new items.
- **Dynamic VAT Dropdowns in Orders & Invoices (`src/components/OrderDetailView.tsx`, `src/components/InvoicingView.tsx`, `src/components/OrdersView.tsx`, `src/App.tsx`)**:
  - Replaced hardcoded VAT option lists with dynamic rates populated from `companyBillingSettings.vatRates`.
  - Added defensive rendering so historical orders or invoices with non-standard tax rates (e.g. legacy 20%) preserve their values without data loss or UI breakage.
  - Automatically pre-selects the configured default VAT rate (23%) when adding custom products, services, delivery fees, or warehouse inventory items.
  - Wired `companyBillingSettings` prop through `App.tsx` into `OrdersView` and `OrderDetailView`.

### v1.12.2-Mango (2026-10-12)
- **Procedural Chinese Landscape Painting Infinite Background (`public/shanshui.html`, `src/components/ShanShuiBackground.tsx`, `src/components/LoginView.tsx`)**:
  - Integrated the authentic procedural Chinese landscape art generation library (`LingDong-/shan-shui-inf`) into the login page.
  - Procedurally generates layered mountains, textured pine trees, pagodas, bridges, boats, and rippling water atop a seamless 4-way symmetrical noise-textured rice paper (宣纸) parchment.
  - Infinite right-to-left scrolling runtime: camera shifts rightwards at a meditative pace (~24 coordinate pixels/sec), continuously streaming fresh terrain into view from the right.
  - Zero-leak chunk pruning: terrain chunks and noise coordinates scrolling past the left viewport boundary are automatically pruned from SVG and memory, maintaining constant $O(1)$ memory consumption indefinitely.
  - Full-screen responsive viewport adaptation: calculates dynamic aspect-ratio SVG viewBox geometry on load and resize, ensuring crisp rendering across ultrawide monitors, laptops, and mobile screens.
  - Preserved login card and digital clock contrast with frosted glass backdrop panes (`bg-white/75`, `backdrop-blur-md`) and deep ink slate typography.
