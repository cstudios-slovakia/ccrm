# Update 1.10 (Codename: Kiwi)

This document tracks all new features, architectural changes, schema migrations, and improvements introduced in the 1.10 Kiwi update cycle.

### v1.10.29-Kiwi (2026-09-18)

- **Version Codename Alignment & Main Branch Integration (`src/utils/version.ts`, `1.10-kiwi-changelog.md`)**:
  - **Codename Alignment to Kiwi**: Formally aligned the 1.10 version codename to **Kiwi** (preserving alphabetical sequence: Grapefruit 1.6, Huckleberry 1.7, Imbe 1.8, Jackfruit 1.9, Kiwi 1.10).
  - **Release Consolidation**: Merged all 1.10 SAI multi-agent simulation sandbox, Mirofish template catalogues, trilingual localizations, dynamic grounding sources, and war room features into the production `main` branch while keeping the `1.10-kiwi` branch intact.

### v1.10.28-Kiwi (2026-09-13)

- **Model Mapping Alignment & Fail-Safe Swarm Persona Batching (`personaSynthesizer.ts`, `ontologyBuilder.ts`, `reportSynthesizer.ts`, `llmProxyClient.ts`, `public/api/swarm.php`, `api/swarm.php`)**:
  - **OpenAI Model Name Mapping in Server Gateway (`public/api/swarm.php`, `api/swarm.php`)**:
    - Synchronized model aliasing across both API directories so internal branding models (`gpt-5.6-luna` and `gpt-5.6-terra`) reliably map to live production endpoints (`gpt-4o-mini` and `gpt-4o`).
    - Increased server-side default token limit to 8000 tokens.
  - **Micro-Batch Persona Synthesis (`personaSynthesizer.ts`)**:
    - Partitioned persona generation into compact, ultra-fast parallel batches of 10 agents with 6000 tokens per batch.
    - Added resilient structured fallback generator for missing agents, guaranteeing persona generation never throws errors.
  - **Token Headroom & Fallback Resilience in Ontology and Report (`ontologyBuilder.ts`, `reportSynthesizer.ts`)**:
    - Raised ontology token ceiling to 8000 tokens and strategic report token ceiling to 10000 tokens with automatic structured fallback builders.
  - **Auto-Retry on Token Length Exhaustion (`llmProxyClient.ts`)**:
    - Added automatic retry with doubled token headroom if OpenAI returns `finish_reason: length`.
