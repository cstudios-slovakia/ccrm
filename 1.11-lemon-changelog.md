# Update 1.11 (Codename: Lemon) — New Features

### v1.11.78-Lemon (2026-09-29)
- **Task Dashboard Card Auto-Growth and Smooth Scrolling**:
  - **Natural Content Expansion (`shrink-0`)**: Fixed an issue where the unified white task card in My Tasks (`#tasks`) was compressed to fit the viewport height instead of growing when multiple tasks were present, causing bottom tasks to be cut off and hidden behind card borders. Added defensive `shrink-0` to guarantee the card always maintains 100% natural content height regardless of task volume.
  - **Fluid Column Scrolling**: Updated the parent task list column container to allow full-height vertical scrolling (`lg:overflow-y-auto overflow-visible h-auto pr-2 pb-8 scrollbar-thin`) with bottom breathing space so all tasks and actions can be scrolled into view cleanly.
  - **Global Tasks Consistency**: Applied the same `shrink-0` and bottom padding protection to the Global Tasks board view.

### v1.11.77-Lemon (2026-09-28)
- **Projects Multi-Status Selection Filter (Matching Leads System)**:
  - **Customizable Status Selection**: Replaced the single-status filter in `#projects` with a flexible multi-selection system identical to `#leads`. Users can now show any custom combination of project statuses (e.g. New + Active + On Hold, leaving out closed ones).
  - **Default Non-Closed State**: By default (or when reset), closed projects (`Completed` and `Cancelled`) are left out, giving users an immediate focus on active work without manual filtering.
  - **Interactive Status Toggle Chips**: Each status chip can be clicked to toggle inclusion/exclusion on the fly, with high-contrast active styling and dimmed idle styling. Option/Alt+Click solos any single status immediately.
  - **One-Click All / Active Toggle**: The "All" chip acts as a quick master toggle: clicking it when all statuses are shown reverts to active-only projects; clicking it when filtered reveals all projects including closed ones.
  - **Persistent User Preference**: The chosen visible statuses are stored in DB-backed user preferences (`projectsVisibleStatuses`) with local fallback and migration, persisting across page reloads and devices.

### v1.11.76-Lemon (2026-09-28)
- **Task Archive Empty State & Filter Cohesion**:
  - **Eliminated Redundant "No Matching Tasks" Banner**: In the Task Archive, the large empty state placeholder is suppressed whenever matching manually archived tasks are present on screen. The empty state now only renders when both completed tasks and manually archived tasks yield zero results under active filters.
  - **Comprehensive Filtering for Archived Tasks**: Manually archived tasks now consistently respect title search, priority, date range, and tag filters in lockstep with completed tasks.

- **Inline Task Tagging (`#tag`) and Entity Mentions (`@entity`)**:
  - **Inline `#tag` Autocomplete & Auto-Creation**: Typing `#` in task titles, descriptions, and quick-add fields triggers an autocomplete suggestion dropdown displaying known tags or offering to create a new tag. Users can navigate suggestions with Arrow keys and select via Enter or Tab. Typing a hashtag and pressing Space automatically creates and links the tag upon saving.
  - **Inline `@mention` Suggestions & Entity Assignment**: Typing `@` triggers suggestions across Team members / Users (Purple), Projects (Amber), Clients (Emerald), and Leads (Sky). Selecting a mention badge automatically assigns that entity to the task (`owner`/`assignedUsers`, `relatedProjectId`, or `relatedLeadId`).
  - **Inline Styled Pills**: Tags and mentions render as styled inline badge pills across task lists, cards, rows, calendar panels, and activity logs.
  - **Tag Archive Filtering**: Clicking any `#tag` pill instantly opens the Tasks Archive view pre-filtered to all tasks carrying that tag, complete with an active filter badge and one-click clear button.
  - **Full-Stack Database & Sync Persistence**: Added `tags` and `task_tags` relational schema in `api/schema.php` and `public/api/schema.php`, with multi-device sync, versioning, and atomic association handling in `sync.php` and `public/sync.php`.

- **Leads and Clients Decoupling & Direct Client Creation**:
  - **Decoupled Pipeline Leads from Clients Register**: Pipeline deals and inquiries (`#leads`) no longer automatically create client entries in `#clients`. Standalone pipeline leads remain strictly in the Sales Pipeline and do not pollute the Clients register unless explicitly created as a client or associated with financial value.
  - **3-Way Client Mode in Lead Creation**: The Lead Creation modal now features a 3-way toggle: `[Žiadny klient / No Client]` (default, creates a pure pipeline lead without client entity), `[Existujúci klient / Existing Client]` (selects from confirmed clients), and `[Nový klient / New Client]` (creates both the lead and registers a new official client profile).
  - **Single-Click Client Creation from Lead**: When viewing a lead without an associated client profile, the lead detail view displays an informative card with a direct `+ Vytvoriť nového klienta z leadu` (`+ Create New Client from Lead`) button to instantly create an official client record in the registry, alongside an option to link to an existing client.
  - **Clients Register Strict Integrity**: Updated client registry aggregation to only include explicit client records (`client-*`) or entities with confirmed positive adjustments/invoiced revenue, ensuring 100% clean data integrity in `#clients`.
