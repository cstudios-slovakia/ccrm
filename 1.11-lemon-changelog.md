# Update 1.11 (Codename: Lemon)

This document tracks all new features, architectural changes, schema migrations, and improvements introduced in the 1.11 Lemon update cycle.

### v1.11.16-Lemon (2026-09-23)

- **Fixed Timeline Date Formatting in Task Dashboard (`src/components/TaskDashboardView.tsx`)**:
  - **Resolved ReferenceError**: Fixed `formatDateHeading` in `renderTimelineView` to call the defined `formatTaskDate` helper rather than the undefined `formatDateDisplay` identifier, preventing runtime crashes on the Tasks view (`#tasks`).

### v1.11.15-Lemon (2026-09-23)

- **Start Menu & Navigation Editor Polish and Layout Resiliency (`src/components/StartMenu.tsx`, `src/components/TaskDashboardView.tsx`)**:
  - **Start Menu Group Header Space Optimization**: Replaced wide text add-button in group headers with a compact icon button (`<Plus className="h-3.5 w-3.5" />`), preventing header action buttons from squishing column titles to 0px on multi-column layouts.
  - **Task Dashboard Layout Cleanup**: Standardized responsive calendar column rendering and cleaned up duplicate block definitions in `TaskDashboardView.tsx`.
  - **Automated QA Test Robustness**: Scoped project tabs and Start Menu dialog assertions in end-to-end journey suites to prevent cross-matching with sidebar navigation items.

### v1.11.14-Lemon (2026-09-22)

- **Comprehensive Navigation Reordering & Direct Group Item Management (`src/components/Sidebar.tsx`, `src/components/StartMenu.tsx`)**:
  - **Inline Reorder Controls in Sidebar & Start Menu**: Added Up (`ChevronUp`) and Down (`ChevronDown`) one-click movement controls for items within custom groups in both the Sidebar and the Start Menu editor, making ordering immediate and effortless.
  - **Direct Group Mover Dropdown**: Added a fast group-destination select menu to items in both the Sidebar and Start Menu when multiple groups are configured, enabling users to instantly transfer modules between navigation groups without dragging.
  - **Inline "+ Add Module" Popover for Groups**: Each group header and empty dropzone in both the Sidebar and Start Menu now includes a direct "+ Add" trigger with a searchable inline popover listing unassigned modules for 1-click addition directly to that group.
  - **Unused Items Quick Group Restore**: In the Start Menu "Unused / Hidden Modules" shelf, added a direct destination dropdown to restore hidden modules straight into any chosen group.
  - **Cross-Component Drag & Drop Reliability**: Implemented global window drag data fallback (`window.__draggedModuleId`) to guarantee cross-window and cross-component drag operations succeed even when browsers restrict `dataTransfer.getData()` during dragover checks.
  - **Eliminated Drag Oscillation**: Replaced disruptive 72px displacement slots during drag-and-drop with slim, non-displacing insertion line indicators, eliminating layout jitter and mouse-leave flickering.
  - **Semantic HTML & QA Compatibility**: Retained native `<motion.button>` elements during normal navigation view to preserve complete accessibility and pass automated QA testing gates, switching to structured container semantics only when editing.

### v1.11.13-Lemon (2026-09-22)

- **Fixed Sidebar Group Management & Persistent Navigation Editing (`src/components/Sidebar.tsx`, `src/components/StartMenu.tsx`, `src/App.tsx`)**:
  - **Prevented Outside-Click Dismissal on Sidebar Controls**: Fixed `handleClickOutside` in `StartMenu.tsx` so clicks on the sidebar (`aside`, `[data-sidebar]`) are never treated as outside clicks during navigation customization. Clicking "+ New Group", rename, or delete buttons no longer causes the Start Menu to close or editing to discontinue.
  - **Sidebar Collapse Protection During Edit Mode**: Updated `Sidebar.tsx` `handleClickOutside` and `onMouseLeave` to prevent auto-collapsing when the navigation editor is active or when interacting between the Start Menu and Sidebar.
  - **Atomic Group & Layout Persistence**: Fixed race conditions and stale closures between `setStoredSidebarGroups` and `handleSaveUserLayout` in `src/App.tsx`. `handleSaveUserLayout` now atomically updates both `navLayout` and `preferences.sidebarGroups`, safely reads latest user metadata inside the updater, and synchronously updates `currentUser` state so removed groups do not reappear on reopen.
  - **Synchronized Edit Mode State**: Added `onEditModeChange` callback between `StartMenu` and `Sidebar` to ensure both components remain perfectly in sync when entering or exiting customization mode.
