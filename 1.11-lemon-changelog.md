# Update 1.11 (Codename: Lemon)

This document tracks all new features, architectural changes, schema migrations, and improvements introduced in the 1.11 Lemon update cycle.

### v1.11.1-Lemon (2026-09-22)

- **Fix (SAI Live War Room & Answer Normalization Engine - `LiveWarRoom.tsx`, `answerNormalizer.ts`, `personaSynthesizer.ts`, `simulationLoop.ts`)**:
  - **Live Consensus Bar Viewport Constraint (`LiveWarRoom.tsx`)**:
    - Fixed an issue where dozens of unique agent answers would wrap into 10–15 rows and squish the ontology graph and social feed into a tiny window at the bottom of the screen.
    - Constrained the consensus bar to a single row with horizontal scrolling (`min-h-[44px] max-h-[50px] overflow-hidden`) displaying the Top 4 leading answers plus a compact `+N others` summary badge.
    - Added `truncate` and `max-w-[170px]` to avoid layout distortion from long answers.
  - **Answer Normalization & Candidate Entity Clustering (`answerNormalizer.ts`, `personaSynthesizer.ts`, `simulationLoop.ts`)**:
    - Introduced `normalizeAnswer` utility matching agent responses against canonical ontology graph entities (e.g. mapping `"Miške Tamás a jövőnk kulcsa!"` and `"Miske Tamás a megfelelő vezető!"` into canonical candidate `"Miške Tamás"`).
    - Enforced strict prompt guidelines requiring agents to output concise 1–3 word option/candidate names in `current_answer` and `initial_answer` instead of entire sentences or slogans.
    - Added comprehensive unit tests in `answerNormalizer.test.ts`.
