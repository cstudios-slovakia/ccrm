# Update 1.11 (Codename: Lemon) — New Features

### v1.11.36-Lemon (2026-09-24)
- **Green Total Value Badge in Leads Equation Breakdown**: Updated the total value pill in the Leads pipeline equation breakdown to render with a vivid emerald green gradient, distinguishing the total calculation from blue-status phase pills and harmonizing with financial value indicators.

### v1.11.35-Lemon (2026-09-24)
- **Configurable Divisions for Leads and Projects**: Added configurable division organization across both Leads and Projects with defaults seeded for "Cstudios" and "Cstudios Budapest".
- **Lead Parameters & Project Card Details Integration**: Embedded division selectors and colored badges directly into the Lead Parameters card, New Lead modal, and Project Card Details.
- **Division Filtering & Sync**: Added comprehensive division filter dropdowns across Leads and Projects views with database schema migrations and multi-device backend synchronization.

### v1.11.34-Lemon (2026-09-24)
- **Fully Colored Status Pills in Equation Statistics**: Upgraded the status breakdown equation pills to render with vibrant full-fill status colors and automatic high-contrast typography, replacing left-border styling.

### v1.11.33-Lemon (2026-09-24)
- **Interactive Expandable Status Equation Statistics**: Added expandable active status value statistics for both Leads and Projects in `<status1> + <status2> + ... = total` format with interactive toggle pills to include or exclude specific active statuses dynamically from the calculated sum.

### v1.11.32-Lemon (2026-09-24)
- **Task Dashboard Mobile Header Responsiveness**: Placed primary view tabs (My Tasks / Global Tasks / Archive) over calendar scope navigation in mobile view and wrapped header controls to eliminate horizontal page scrolling on mobile devices.

### v1.11.30-Lemon (2026-09-24)
- **Soft Dynamic Aurora Ambient Backgrounds**: Added organic glowing aurora mesh gradient blobs in the background behind every view, dynamically adapting their primary and secondary color palettes to match the active view's sidebar icon.
