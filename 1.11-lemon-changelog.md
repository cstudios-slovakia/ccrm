# Update 1.11 (Codename: Lemon)

This document tracks all new features, architectural changes, schema migrations, and improvements introduced in the 1.11 Lemon update cycle.

### v1.11.26-Lemon (2026-09-23)

- **Browser Web Push Notifications for Tasks (`src/utils/browserNotifications.ts`, `src/App.tsx`)**:
  - Added browser desktop notification capability using the HTML5 Notifications API.
  - **New Task Assignment Push**: Pushes a browser notification to the assigned user when a new task is created or assigned to them by a team member.
  - **Task Completed Push**: Pushes a browser notification to the creator of a task when the assignee marks it as `Done`.
  - Seamless navigation back into `#tasks` upon clicking the desktop notification.

### v1.11.25-Lemon (2026-09-23)

- **Two-Line Task Item Layout (`src/components/TaskDashboardView.tsx`)**:
  - Restructured task row items into two distinct horizontal lines for maximum clarity and clean hierarchy:
    - **Line 1**: Status select dropdown + Distinct priority glyph icon + Task title.
    - **Line 2**: Metadata badges (Delegated badge, Lead/Client, Project, Due date & time, Assignee, Description preview).

### v1.11.24-Lemon (2026-09-23)

- **Inline Batch Task Creation Card (`src/components/TaskDashboardView.tsx`)**:
  - Replaced the side drawer modal with an inline creation card directly above the task list that seamlessly matches the column width.
  - **Shift + Enter & Multiline Batching**: Typing multiple task titles on separate lines (or pasting multiline text) generates individual tasks in batch sharing identical configuration (due date/time, priority, assigned project manager, project/client link).
  - **Streamlined Inputs**: Removed Start Date and Description from initial creation to allow rapid-fire task capture (descriptions can be added post-creation in the task details drawer).
- **Persistent Display Mode Cookie (`src/components/TaskDashboardView.tsx`)**:
  - Saved the user's active calendar display mode (`month`, `week`, `timeline`, `hide`) into the `ccrm_task_calendar_scope` cookie with a 1-year max age so chosen view modes persist across sessions and page reloads.

### v1.11.20-Lemon (2026-09-23)

### v1.11.19-Lemon (2026-09-23)

- **Multi-Select & Floating Bulk Actions Toolbar for Tasks (`src/components/TaskDashboardView.tsx`)**:
  - **Task Selection & Multi-Select Checkboxes**: Integrated accessible selection checkboxes onto all task cards across My Tasks, Global Tasks, and Archive views (including both completed task logs and manually archived tasks). Selected cards highlight with a clean indigo accent background and ring indicator.
  - **View-Level "Select All" Controls**: Added one-click "Select all visible" toggle buttons to Personal Schedule, Global Tasks filter bar, and Archive header to quickly select or deselect all currently visible tasks.
  - **Floating Glassmorphic Bulk Actions Bar**: Created a modern bottom-centered floating toolbar that smoothly appears when tasks are selected. Features include:
    - **Selection Counter & Clear**: Displays total selected count with quick "Deselect" and "Clear" (`X`) actions.
    - **Bulk Status Update**: Dropdown to transition all selected editable tasks across any workflow state (To Do, In Progress, Blocked, Done, etc.) with automated `completedAt` and `completedBy` assignment.
    - **Bulk Priority Assignment**: Dropdown to set priority level (Low, Medium, High) across all selected tasks simultaneously.
    - **Bulk Assignee Reallocation**: Dropdown menu allowing 1-click reassignment of selected tasks to any team member.
    - **Bulk Reschedule**: Popover datepicker providing rapid shortcuts (Today, Tomorrow, +1 Week) as well as custom date selection to reschedule deadlines for selected tasks.
    - **Bulk Archive & Restore**: Context-aware 1-click action to archive active selected tasks or restore archived items back to active status.
    - **Bulk Permanent Deletion**: Delete trigger with confirmation dialog and parallelized backend deletion requests.
  - **Permission-Aware Execution**: Fully respects role-based permissions (`mayEditTask`, `mayArchiveTask`, `mayDeleteTask`), gracefully executing permitted actions while notifying the user via localized toast feedback if any tasks were skipped.
  - **Multilingual Support**: Complete SK, HU, and EN translations for all toolbar controls, count labels, quick date buttons, and feedback toasts.
