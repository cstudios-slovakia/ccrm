# Update 1.11 (Codename: Lemon) — New Features

### v1.11.44-Lemon (2026-09-25)
- **High-Fidelity Microphone Capture & Noise Suppression**: Added hardware acoustic echo cancellation (`echoCancellation: true`), background noise suppression (`noiseSuppression: true`), and automatic microphone gain control (`autoGainControl: true`) to `getUserMedia` voice capture.
- **Reliable Audio Buffer Flushing & Safe Lifecycle**: Fixed audio truncation by ensuring `MediaRecorder.requestData()` and `onstop` fully complete and encode all Opus audio frames before releasing audio tracks and closing Web Audio context.
- **Multilingual Whisper Vocabulary Prompting**: Integrated targeted CRM vocabulary prompts and language guidance (`sk`, `hu`, `en`, `cs`) into the Whisper transcription engine, boosting speech recognition accuracy for Slovak, Hungarian, and English voice task commands.
- **Voice Transcription Feedback in Toast**: Success notifications now display both the created task titles and the exact speech transcription recognized by AI.

### v1.11.43-Lemon (2026-09-25)
- **Dynamic PWA App Name from Configured System Name**: When installing the PWA or adding the CRM to a mobile device home screen (Android, iOS / iPadOS, Windows, macOS, Chrome OS), the installation title and home screen icon label now dynamically reflect the configured workspace `systemName` (e.g. from Settings > Branding) instead of a fixed "CCRM".
- **Dynamic Web App Manifest Endpoint (`/api/manifest.php`)**: Built dynamic manifest generator querying `system_settings.SYSTEM_NAME` with server-side rewriting from `/manifest.json` and client-side Blob URL synchronization for immediate runtime updates.
- **Apple Mobile & Application Meta Tags**: Added dynamic synchronization of `<meta name="apple-mobile-web-app-title">` and `<meta name="application-name">` with pre-mount HTML boot script and React state synchronization.

### v1.11.42-Lemon (2026-09-25)
- **Voice Task Recording Across Leads, Clients, and Projects**: Integrated the unified `VoiceTaskActionBar` component into Lead Detail drawers (phase-gate tasks), Project Tasks panels, and Client detail drawers (`#clients` tasks tab).
- **Automatic Entity Autoselection**: Tasks recorded or created via the voice tool automatically link to the active context:
  - **Leads**: automatically links `relatedLeadId: activeLead.id` and preserves locking/gate task mode (`isLocking`).
  - **Projects**: automatically links `relatedProjectId: project.id` and `relatedLeadId: project.leadId`.
  - **Clients**: automatically links `relatedLeadId: clientPrimaryLeadId` and associates tasks with the client's leads.
- **Client Detail Tasks Tab & Management**: Added a dedicated `tasks` tab inside the client drawer with open/completed task lists, live counters, inline batch task creator, and full `TaskEditDrawer` support.

### v1.11.41-Lemon (2026-09-25)
- **Dynamic 80%/20% Recording Expansion & Squeeze Animation**: When starting a voice recording, the recording button smoothly expands to 80% width while the "+ Create New Task" button gracefully squeezes down to 20% width.
- **Right-to-Left Live Sound Wave Stream**: Audio wave bars now dynamically stream from right to left in real time based on live microphone frequency data, giving continuous fluid audio feedback.
- **Whole-Button Task Submission**: The entire 80% recording button is now clickable to immediately stop recording and send/create the task, with the dedicated Cancel `X` button on the far right preserving isolated cancel/discard functionality.

### v1.11.40-Lemon (2026-09-25)
- **Voice Task Recording & AI Task Creation (80% / 20% Layout)**: Added a "Record Task" button next to the "Create New Task" button on the Tasks dashboard (`#tasks`), occupying 20% width alongside the 80% width "+ Create New Task" button.
- **Interactive Voice Recording Bar & Audio Visualizer**: When clicked, the action bar seamlessly transforms into an active recording pill displaying live duration timer, animated frequency equalizer bars, and a pulsing status indicator.
- **Stop & Send and Cancel Controls**: Includes intuitive control buttons directly inside the recording indicator to either cancel and discard the recording, or stop and immediately send it for AI transcription and automatic task creation.
- **AI Audio Transcription & Smart CRM Task Extraction**: Built `/api/transcribe_task.php` integrating OpenAI Whisper for multi-language speech transcription (Slovak, Hungarian, English, Czech) and OpenAI GPT for intelligent parsing of task titles, descriptions, due dates/times, priority levels, and assignee matching.

### v1.11.39-Lemon (2026-09-25)
- **Streamlined Projects Equation Card**: Removed the redundant bottom "Remaining Invoicable" highlight banner from the Projects group container, maintaining a clean and unified status equation badge layout where badges directly convey pending invoicable amounts.

### v1.11.38-Lemon (2026-09-25)
- **Invoicable-Only Status Values Across Equation Badges**: Updated all status pill statistics (Pipeline Leads, Projects, Dashboard) to strictly display invoicable amounts (`Remaining Invoicable = Math.max(0, Project Budget - Invoiced Income)`), ensuring status values accurately represent pending billable scope.
- **Show/Hide Eye Icon on Every Status Badge**: Added dedicated `Eye` / `EyeOff` icons on every status badge to intuitively toggle inclusion/exclusion from group equation subtotals and the grand equation total.
- **Detailed Item Inspection Slideout Drawer**: Added an `Info` icon button on every badge opening a comprehensive right slideout drawer that lists all individual leads and projects calculated within that status, complete with real-time text search, budget breakdown (Total Budget, Invoiced So Far, Invoicable), client names, project managers, divisions, and direct deep links into CRM entities.
- **Unified Grouped Status Equation Statistics on Dashboard**: Combined Leads pipeline and Projects budget status equation statistics into a single grouped dashboard component (`#dashboard` and `#overview`) with distinctly tinted and styled group containers (blue for Leads, purple for Projects).
- **Interactive Multi-Group Status Equation**: Supported interactive status pill toggling per group to dynamically include or exclude individual statuses from group subtotals and the grand total equation calculation.
- **Persistent Remaining Invoicable Value Metric**: Integrated a prominent, always-visible remaining invoicable calculation (`Remaining = Active Projects Value - Invoiced Income`) with detailed budget vs invoiced breakdown in the Projects group container and collapsed preview badges.
