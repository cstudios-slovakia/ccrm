# Update 1.11 (Codename: Lemon)

This document tracks all new features, architectural changes, schema migrations, and improvements introduced in the 1.11 Lemon update cycle.

### v1.11.5-Lemon (2026-09-22)

- **Balanced 2.0x macOS Dock Magnification (`src/components/Sidebar.tsx`)**:
  - **Calibrated 2.0x Peak Scale**: Adjusted the dynamic dock magnification curve to a balanced `2.0x` peak scale (`1 + bell * 1.0`), providing an elegant, crisp magnification effect without overwhelming screen real estate.
  - **Harmonized 130px Influence Radius**: Tuned the vertical proximity wave radius to `130px`, ensuring smooth, fluid wave transitions across adjacent navigation icons.
  - **Refined Floating Tooltip & Soft Shadows**: Optimized tooltip horizontal positioning (`+16px` margin) and calibrated soft ambient drop shadows for the 2.0x zoom level.

### v1.11.4-Lemon (2026-09-22)

- **Seamless Start Menu to Open Sidebar Drag-and-Drop Workflow (`src/components/Sidebar.tsx`, `src/components/StartMenu.tsx`)**:
  - **Auto-Expanded Navigation on Edit**: Clicking "Edit Navigation" now immediately expands the left navigation sidebar and elevates it above the Start Menu backdrop (`z-[100001]`), keeping all groups and items fully visible and interactive.
  - **Dual Side-by-Side Canvas Layout**: Offset the Start Menu dialog container on desktop (`lg:pl-72 lg:pr-8`) so both the full Start Menu application catalogue and the open left navigation sidebar are completely unobstructed.
  - **Interactive Group Dropzones & Visual Feedback**: Added animated dashed drop targets to every sidebar group in edit mode with instant dragOver glowing highlights, plus quick-remove unpin buttons (`X`) on pinned sidebar items.
  - **Editing Toolbar & State Synchronisation**: Added an "Editing Navigation" status toolbar at the top of the sidebar with a one-click "Done" button to exit edit mode and restore normal navigation.

### v1.11.3-Lemon (2026-09-22)

- **Amplified 5x+ Dynamic macOS Dock Magnification & Overflow Breakout (`src/components/Sidebar.tsx`)**:
  - **Amplified Dynamic Magnification (5.2x Peak Scale)**: Reworked the dock magnification wave to reach up to `5.2x` magnification with a smooth cosine bell curve (`(cos(norm * PI) + 1)/2 * 4.2`) and an extended 200px influence radius for authentic fluid wave dynamics.
  - **Navigation Bar Breakout (`overflow-visible`)**: Configured desktop `<aside>` and `<nav>` to allow scaled icons to project freely outwards from the navigation bar directly over the workspace without boundary clipping or scroll cutoffs.
  - **Layered 3D Z-Index & Dynamic Elevation**: Implemented dynamic z-indexing (`zIndex: scale * 100`) and elevated drop shadows so the most magnified icon rises naturally to the top of the stack and hovers over sibling items.
  - **Fluid Tooltip Positioning**: Dynamically adjusted the floating tooltip offset based on real-time magnification width so labels float smoothly alongside the enlarged icon.

### v1.11.2-Lemon (2026-09-22)

- **Navigation Settings in Personal Settings Sidebar Drawer (`src/components/Header.tsx`, `src/components/SidebarSettings.tsx`)**:
  - **Embedded Navigation Settings in Quick Profile Drawer**: Integrated the complete `SidebarSettings` panel directly into the right-hand slideout user profile / personal settings drawer in `Header.tsx`.
  - **Compact Responsive Drawer Layout**: Added responsive compact mode (`compact` prop) to `SidebarSettings` with single-column stacking, streamlined card padding, and responsive density options tailored for the slideout panel.
  - **Direct Access to Sidebar Controls**: Users can now change sidebar attachment (floating overlay vs pinned column with inner depth shadow), compactness density (compact, comfortable, spacious), unpinned interaction style (flyout vs dynamic macOS Dock), and manage navigation groups directly from the header drawer without having to leave their active workspace.

### v1.11.1-Lemon (2026-09-22)

- **Comprehensive Navigation Sidebar Rework (`src/components/Sidebar.tsx`, `src/components/StartMenu.tsx`, `src/components/SidebarSettings.tsx`, `src/components/PersonalSettingsView.tsx`, `src/utils/userPrefs.ts`, `src/utils/sidebarLayout.ts`)**:
  - **Start Menu Direct Drag-and-Drop Editing**: Eliminated the redundant second sidebar drawer panel. Clicking "Edit Navigation" now opens the Start Menu in full edit mode with draggable module tiles to place/pin directly onto the sidebar and vice versa.
  - **Left Pinning with Recessed Depth Shadow**: Introduced permanent left column pinning mode (`sidebarPinned`). When pinned, the sidebar renders a prominent right inner depth shadow (`shadow-[inset_-10px_0_16px_-6px_rgba(0,0,0,0.08)]`), visually receding behind the workspace surface to the right, with viewport spacers preventing any content overlap.
  - **Compactness Density Customization**: Added 3 selectable compactness levels (`sidebarCompactness`): **Compact** (64px collapsed, 224px expanded, dense padding), **Comfortable** (80px collapsed, 256px expanded, default), and **Spacious** (96px collapsed, 288px expanded, generous hit targets).
  - **Custom Sidebar Navigation Groups**: Added full support for organizing sidebar items into custom groups (`sidebarGroups`). When expanded or pinned, distinct group headers are rendered; when collapsed or unpinned, groups are cleanly separated by subtle divider lines.
  - **Dynamic macOS Dock Mode**: Added an interactive macOS-style dynamic magnification mode (`sidebarUnpinnedStyle === "dock"`) when unpinned. Moving the mouse across icons smoothly scales them up based on vertical cursor proximity and renders a sleek floating tooltip with module details to the right.
  - **Personal Settings Integration**: Added a dedicated "Sidebar & Navigation" configuration suite to Personal Settings (`PersonalSettingsView.tsx` and `SidebarSettings.tsx`), giving users full interactive control over attachment mode, density, interaction style, and group hierarchies with instant persistence.
  - **Comprehensive Test Suite & Verification**: Added unit tests for group normalization and sanitization in `src/utils/sidebarLayout.test.ts` (422 unit tests passing) and validated full end-to-end accessibility, dark mode, and navigation crawler audit suites.
