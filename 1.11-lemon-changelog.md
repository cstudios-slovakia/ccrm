# Update 1.11 (Codename: Lemon) — New Features

### v1.11.26-Lemon (2026-09-23)
- **Browser Push Notifications**: Desktop push notifications via HTML5 Notifications API when a task is assigned to you or when a task you created is completed.

### v1.11.25-Lemon (2026-09-23)
- **Two-Line Task Item Layout**: Clean 2-line visual hierarchy (Line 1: Status + Priority glyph + Title; Line 2: Badges, Lead/Project, Due date & time, Assignee).

### v1.11.24-Lemon (2026-09-23)
- **Inline Batch Task Creation**: Inline card above schedule with multiline <kbd>Shift</kbd>+<kbd>Enter</kbd> (or paste) support to create multiple tasks in one batch.
- **Persistent Calendar View Mode**: Active calendar display mode (Month, Week, Timeline, Hide) persisted across sessions via cookies.

### v1.11.22-Lemon (2026-09-23)
- **Distinct Priority Glyph Icons**: Distinct visual icons for each priority tier (Flame for High/Urgent, Arrows for Medium, Minus for Low).

### v1.11.20 – v1.11.21-Lemon (2026-09-23)
- **Unified Single-Card Task Dashboard**: Consolidated schedule container with collapsible sections (Overdue, Today, Tomorrow, Future).
- **Unified Delegated Tasks**: Delegated tasks merged side-by-side with personal tasks in primary schedule buckets with distinct attribution badges.

### v1.11.19-Lemon (2026-09-23)
- **Task Multi-Select & Floating Bulk Actions**: Multi-card selection with a floating toolbar for bulk status changes, priority assignment, team reassignment, rescheduling, archiving, and deletion.

### v1.11.17-Lemon (2026-09-23)
- **Split-Pane Timeline View**: Activity & history timeline rendered directly in the right-hand column alongside personal tasks.

### v1.11.14-Lemon (2026-09-22)
- **Navigation Reordering & Group Management**: Up/Down movement controls, fast group-destination mover dropdowns, and inline "+ Add Module" popovers in Sidebar and Start Menu.

### v1.11.10-Lemon (2026-09-22)
- **Default Start Screen Configuration**: Quick startup screen selector in Start Menu footer, edit toolbar, and one-click default badges on module tiles.

### v1.11.6 – v1.11.7-Lemon (2026-09-22)
- **macOS Dock Magnification**: Physics-based spring magnification and mutual push-away icon displacement for unpinned sidebar dock mode.

### v1.11.1 – v1.11.4-Lemon (2026-09-22)
- **Modern Sidebar & Start Menu Customization**: Direct Start Menu drag-and-drop navigation editor, permanent left column pinning with recessed depth shadow, custom navigation groups, and 3 density modes (Compact, Comfortable, Spacious).
- **Navigation Settings Drawer**: Quick sidebar appearance and interaction settings embedded in the profile slideout drawer.

### v1.11.0-Lemon (2026-09-22)
- **SAI Answer Mode**: Dynamic question decision engine integrated into the workspace.
- **Structure & Project Organization**: Visual organizational hierarchy and project drag-and-drop reordering.
